# Maths & Science Crusade - Educational Platform

Welcome to the Maths & Science Crusade repository! This project is an educational web platform designed to provide comprehensive learning resources for mathematics, physics, and chemistry subjects.

**Live Demo:** [Maths & Science Crusade](https://mathway-app.vercel.app/)

## 📋 Project Overview

Maths & Science Crusade is a responsive educational website built with HTML5, CSS3, and JavaScript. It offers a user-friendly interface for students to learn various STEM subjects with structured content, practice resources, and user authentication features.

## ✨ Features

- **Multi-Subject Support**: Learn Mathematics, Physics, and Chemistry
- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **User Authentication**: Login and registration system
- **Practice Resources**: Dedicated practice area for problem-solving
- **Color Themes**: Multiple color scheme options (5 themes)
- **Contact System**: Get in touch with instructors and support team
- **Terms & Conditions**: Clear legal framework

## 🛠 Technologies Used

- **HTML5**: Semantic markup and structure
- **CSS3**: Advanced styling with Bootstrap 5 framework
- **JavaScript (Vanilla)**: Interactive features and form validation
- **Bootstrap 5**: Responsive grid system and components
- **Font Awesome**: Icon library

## 📄 Key Pages

| Page | Purpose |
|------|---------|
| `index.html` | Homepage with navigation and featured content |
| `mathematics.html` | Mathematics learning resources |

| `practice.html` | Practice problems and exercises |

## 🎨 CSS Organization

- **Main Styles**: `home.css` contains core styling for layout and components
- **Responsive Design**: `responsive.css` handles breakpoints for all devices
- **Terms Page**: `terms.css` provides specific styling for the terms page
- **Color Themes**: The `color/` directory contains 5 interchangeable color schemes

## 📱 JavaScript Modules

- **home.js**: Handles navigation menu toggle and dropdown menus
- **pages.js**: Page-specific interactive behaviors
- **registrationVerificatio.js**: Form validation for user registration and login
